How do we learn about the universe?

Scientists use observations, physics, and powerful tools to investigate the biggest questions.

🔭

1. Observe

Telescopes collect light from distant objects, helping scientists study stars and galaxies.

📊

2. Find patterns

Scientists compare measurements and use mathematics to test ideas about the cosmos.

🤖

3. Explore with AI

AI can help sort telescope data and spot patterns for researchers to investigate.

Science reminder: This is an educational website. Ask questions, check evidence, and remember scientific explanations can improve with new observations. Astro is a simple demo assistant, not a live AI model.
